# 页面专项规则模板

id / version / status(candidate|active|retired) / pages / modes / profiles / source / evidence / validFrom / validUntil。

1. 页面职责、实际模块与字段，数据与空状态。
2. 参考观察 observation：URL、采集时间、视口、原始截图/DOM数据；无法访问就记录缺口。
3. 硬要求 required：业务来源与适用范围。
4. 制作预算 target：PC/手机宽高、字号行高、四层累计间距、图像与CTA空间；解释为什么。
5. 例外 exception：长内容、既有基线、明确授权与不得外溢的范围。
6. 生成方法：作用域、断点、真实数据/状态，保留品牌自由。
7. 审核方法：实际页面/状态矩阵、几何/文本/像素与真实操作、证据要求。
8. 验证：代表样本、独立结论、未检查项、失败修复及新候选。

未验证条目保持 candidate，补全后注册索引，不复制详情数值充当首页实测。
