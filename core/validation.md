# 遮蔽测试与回归

日常独立审核：作者/审核角色分离，审核先看候选像素，记录首印象后再看作者说明。已知回归用例仍需覆盖，不必对所有普通维护启动历史遮蔽实验。

验证新知识是否有用时可使用遮蔽测试：协调者只向作者提供需求、合法参考、冻结数据与选中规则；历史交付与旧评语暂存包外且不列入作者输入。作者制作后 freeze，独立角色只看候选和适用标准完成整轮审核，seal-review 封存结论后再 reveal 历史交付用于比较。返工新建 run，禁止回改已冻结结果。

bin/blind.mjs 只做文件冻结与一致性核验，不是权限沙箱。拥有整个磁盘读取权的 Agent 仍能查看包外历史；需要真正遮蔽时由宿主提供分离上下文/只读挂载，并记录实际工具范围。若历史已提前暴露，记录 contaminated，不能称盲测。不能隐藏必要业务要求或安全边界。

报告对比旧/新规则下的实际结果和失败，不能把相同作者的自评、哈希一致、单次良好截图当成跨 Agent 有效性证明。工具或授权不允许的操作记 not-run，禁止换通道绕过。
