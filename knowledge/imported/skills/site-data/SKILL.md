# 网站数据

## Harness 接入

此技能已安装到 Harness 自有技能目录，Web 与 SDK 共用。生成前读取 `site_harness(action="workflow")` 的 `siteData` 契约。新设计及新建复用站点导入时会自动获取公共库快照，在项目内安装此技能、`src/site-data.mjs` 和 `docs/site-data.json`，原始响应及证据位于 `docs/content-evidence/coupon-api/`。

先读取该快照，避免重复取数。`src/site-data.mjs` 导出 `siteData` 及 `meta/home/recommendedStores/categories/blogs/events`；`home` 含 `store/coupon` 数组，其余字段已按实际 envelope 解包。数据是有数量上限的页面种子，不是全量库；完整商家/优惠详情按下文接口补充。将字段转换、市场筛选和页面选集写在独立展示模块（例如 `src/site-catalogue.mjs`）中，不修改冻结快照。实际 renderer 和 client 都使用这一份数据，构建会检查 renderer 是否依赖该模块及快照哈希。

按既有 Harness 内容 schema 写 `docs/content-provenance.json`，其中 source URL、获取时间、rawPath 和 SHA-256 可从 `docs/site-data.json` 的 `sources` 读取；商家/优惠/分类只记录实际选用的数据。额外 GET 响应也保存为项目内的证据文件，来源应仍是同一公共 API。API 不可达会阻止新站导入，不回退到旧 ChoiceInsiders 或示例数据。已有 preserve 项目及历史冻结产物继续使用其已确认数据。

## 默认来源

用户指定：后续所有生成站点的数据内容均从[新coupon公共库供后续站点使用](https://tanyueco.feishu.cn/wiki/N2exwDwzpiYaV6kXoZvcmW9cnie)定义的公共库获取。除非用户在当前任务明确指定其他来源，始终应用此规则。

飞书文档是接口与字段说明；页面实际内容来自它定义的公共库 GET API，或由该 API 生成且能确认来源的站点 JSON。不要把飞书说明文字当成商家或优惠券数据。

生成站点前阅读 [references/coupon-api.md](references/coupon-api.md)，按页面选择所需接口。该参考于 2026-10-09 从文档核对；接口或字段有变更迹象时重新读取飞书，以最新文档和实际响应为准。

## 快速取数

1. 确定站点市场、语言及页面范围。API 的 `lang` 默认是 `us`；其他语言代码应从项目配置或接口实际支持值确认，不要自行把 `en`、`en-US` 等当作 API 代码。
2. 优先复用本次任务已读取的公共库响应或来源明确的 JSON。已实测的默认 API origin 为 `http://new.sp.com`，接口前缀为 `/open-api/coupon`；2026-10-09 在当前网络下，11 个 GET 接口均成功返回真实数据，无需 Cookie 或 Token。新任务先做一次所需接口的 GET 请求确认可达；项目有更新的明确配置时采用该配置。文档中的 `http://172.18.188.6:4224/` 是管理面板入口，不是本次实测的公共 API origin。
3. 按实际页面取数：首页先取 `/home`；分类导航取 `/all-categories`；商家页取对应商家详情；优惠详情取对应 CID。独立查询可以并行。同一商家、CID 或接口响应在本次任务复用，不反复全量拉取。
4. 保留原始响应，统一转换成站点共享数据模块或构建时 JSON，所有页面与浏览器交互使用同一份数据。静态 HTML/ZIP 交付应能离线展示已获取内容；搜索和筛选使用本地数据时，明确其覆盖范围。
5. 记录来源文档、实际接口、`lang`、获取时间和使用的 SID/CID/Slug，放在开发交付资料中，不塞进用户页面。

## 内容约束

- 商家名称、Logo、官网、优惠标题、优惠码、折扣、使用条款、有效期、分类、活动和 Blog 内容必须取自公共库。保留 SID、CID、Slug 和原始链接，不能为凑卡片数量虚构记录。
- 商家与优惠券关联、市场和语言以实际返回为准；优惠券的市场、语言和 Logo 继承所属商家。`lang=us` 实测同时返回 GB、US、CA 商家，不能把语言参数当作市场过滤；有目标市场时在已获取数据中按 `market` 筛选，并核对商家及优惠券关联。去重时用源数据 ID，不按名称猜测。
- `coupon_code` 类型才展示复制优惠码交互，且必须有实际优惠码；其他类型依据数据展示领取或跳转。详情链接、官网、优惠跳转链接和来源链接按用途使用，不能互相冒充。
- 日期不明确时不编造到期日；缺失图片、描述或条款时可隐藏对应元素或使用中性空状态。仅在响应有依据时显示“已验证”、成功率、使用人数、独家、评分等事实标签。
- 导航、按钮及通用提示可按设计与页面语言撰写或翻译，不能借此新增优惠事实或伪造公共库文章。
- 公共库缺少某类站点所需内容时，先完成不依赖该数据的布局，并说明缺口。访问失败时使用来源明确且标注获取时间的缓存；没有可用缓存就说明阻塞，不以模拟数据冒充取数成功。
- 文档中的数据库凭据不复制到 skill、前端、交付包、Git 或输出；取数优先使用 GET API。建站取数不包括执行爬取、管理面板维护或数据上线操作。

## 交付核对

确认页面显示内容能对应到公共库记录；商家、优惠券和详情跳转关系正确；语言与市场一致；优惠码、有效期和图片来自响应；空数据处理可用。说明实际使用的数据来源和任何缓存或缺失情况。
