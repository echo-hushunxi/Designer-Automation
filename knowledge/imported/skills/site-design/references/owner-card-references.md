# Owner references: shared flow, distinct cards

Inspected in the real browser on 2026-09-20, desktop viewport approximately 1265×712. These are visual observations, not endorsement of every content/interaction pattern. No claims about their mobile layout or copy reliability were tested in this study.

Compared the same Spectrum store and the same offer (601010) across all three sites:

| Reference | Observed card language | Transferable design lesson |
| --- | --- | --- |
| [Dealmerica store](https://dealmerica.com/businessList/spectrum.html), [detail](https://dealmerica.com/businessDetail/601010.html) | Relatively light horizontal store rows with a distinct action tail and orange/red gradient buttons. The detail is a centered vertical coupon with logo above headline, broad code region and full-width action. | Main coupon can have a different emphasis from browsing rows while keeping a coherent identity. The observed vertical detail is reference analysis, not permission to override the owner's agreed information/action relationship. |
| [ChoiceInsiders store](https://choiceinsiders.com/businessList/spectrum.html), [detail](https://choiceinsiders.com/businessDetail/601010.html) | Warm-tinted identity/main panels with a thin red top edge; logo separated from content; store coupons use ticket notches/serrated edges and folded-corner action buttons. | Surface, separation and the actual CTA jointly establish identity within a familiar horizontal browsing arrangement. |
| [Couponbon store](https://couponbon.com/businessList/spectrum.html), [detail](https://couponbon.com/businessDetail/601010.html) | Light-grey page with rounded white panels, stronger merchant headings and accent count chips; broad softly tinted/dashed code box; rounded main action and peel-corner list actions. | Similar information order can still feel different through proportions, type hierarchy, material and action construction. |

Do not copy advertisements, reserved ad whitespace, watch-an-ad gating, unsupported claims, decorative labels, missing-logo placeholders or reference font sizes. This project's truthfulness, typography, logo, claim behavior and HTML ZIP contract apply. Do not turn ticket edges, peel corners, red gradients or any reference arrangement into the next universal template.

Acceptance question: with the same merchant and offer content, do store identity cards, coupon rows, main coupon and related offers express this site's coherent identity? If only names/colors differ, return a concrete revision request. If the business skeleton is familiar but the composed card design is recognizably different and usable, it can pass.
